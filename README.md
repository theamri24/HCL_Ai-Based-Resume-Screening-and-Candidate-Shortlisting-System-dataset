\# 🧠 AI Resume Screening \& Candidate Shortlisting System



An AI-powered resume screening tool that helps HR teams automatically analyze resumes, extract skills, score candidates against job requirements, and shortlist them — all in a professional Streamlit dashboard.



\## 🚀 Features



\- 🔐 Secure login with bcrypt password hashing

\- 💼 Job posting management

\- 📤 Resume upload (PDF + DOCX)

\- 🧠 NLP-based skill \& keyword extraction

\- 📊 TF-IDF job description similarity matching

\- 🤖 ML model (Gradient Boosting) for resume scoring

\- ✅ Auto shortlist / review / reject decisions

\- 👥 Candidate search, filter, and detail view

\- 📈 Analytics dashboard with insights

\- 💾 MySQL storage for all data

\- 🎨 Professional HR-style UI
